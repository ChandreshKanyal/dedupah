01Connect your sources

Upload a file or connect a database, warehouse, object store, SFTP folder or CRM. Each source is read the way its vendor documents, and passwords stay in your environment, never in the portal.

Every likely pair gets a score from all the fields the two records share, and you can see exactly which fields agreed. High scores merge, the middle goes to a person, the rest stay apart.

Rules

Rules written in sentences, not code

The rules that overrule a score read like policy. Change one, try it on your latest run, then make it live, with a second person's approval when your process needs one.

Never merge

Security

Built for regulated customer data

01

Aadhaar is never stored

It becomes a keyed token at the door. Only that token is compared.

02

Masked until needed

Identifiers stay hidden until someone with permission opens them, and every view is logged.

03

A log that shows tampering

Sign-ins, views, exports and decisions are chained by hash, so an edited entry stands out.

04

Two people for rule changes

A project can require a second person to approve a change before it goes live.

05

Encrypted at rest

Working files of every run are encrypted with your own key.

06

Inside your network

Designed to run on your own servers. Customer data does not leave them.
